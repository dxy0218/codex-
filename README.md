# 虚拟股市训练器（Windows）

这是一个可在 Windows 运行的 Python 桌面程序：
- 实时拉取真实市场行情（默认美股、A股/港股、日股、欧股示例）
- 支持账户创建与登录（每个账户独立组合）
- 模拟买入/卖出与持仓管理（练习盘）
- 自动记录并持久化操作历史，可随时在软件内查看
- 支持股票查询、自选股、侧边股票栏、实时大盘行情、首页大盘/期货K线、金融资讯、交易记录导出、收益曲线、均线策略回测与期货模拟
- 通过 **OpenAI 会员订阅模式** 接入 AI 训练（不走 API 按量计费）
- 内置投资限制（单笔上限 + 总投资上限），避免练习结果偏离现实

## 1. 环境准备

1. 安装 Python 3.10+
2. 在项目目录执行：

```bash
pip install -r requirements.txt
```

## 2. 运行

```bash
python app.py
```

## 3. 会员订阅模式 AI 训练

点击按钮“会员AI训练”后：
1. 程序自动生成训练提示词
2. 自动打开 ChatGPT 网页（`chatgpt.com`）
3. 使用你的会员账号继续训练

> 该方式不调用 API，不需要 `OPENAI_API_KEY`，可减少实际 token 消耗。

## 4. 风险与现实约束

程序默认限制：
- 单笔交易上限：`200,000`
- 总投资上限：`1,000,000`

你可以在 `app.py` 中修改：
- `MAX_SINGLE_TRADE`
- `MAX_TOTAL_EXPOSURE`

## 5. 打包为 Windows 可执行文件（可选）

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed app.py
```

生成的 exe 在 `dist/app.exe`。

## 6. 说明

- 数据源使用 `yfinance`，不同市场代码格式不同（例如 `7203.T`、`0700.HK`）。
- 默认每 5 秒尝试刷新一次当前关注标的价格。
- 这是训练软件，不构成投资建议。


## 7. 账户与历史记录

- 首次启动可直接创建账户，随后登录。
- 每次买入、卖出、发起 AI 训练都会写入历史记录。
- 用户数据保存在程序目录下的 `stock_trainer.sqlite3`。
- 新版本不再保存明文密码；使用 PBKDF2-SHA256 + salt 保存密码哈希。
- 旧版 `users.json` 会在首次启动时自动迁移到 SQLite，并重命名为 `.migrated-*.json` 备份。

## 8. 功能说明

### 股票搜索 / 自选股

- UI 已调整为类似行情客户端的深色终端布局。
- 顶部显示实时大盘指数条，包括上证、深证、恒生、日经、标普、纳指、道指。
- 左侧提供大盘指数表和自选股票栏，可快速添加关注股票。
- 在“股票搜索 / 自选股”标签页输入代码，例如 `AAPL`、`MSFT`、`0700.HK`。
- 可查询最近价格摘要、加入自选股、双击自选股设为当前交易代码。
- 自选股会保存在当前用户数据中。

### 导出

- “导出交易CSV”：导出当前账户操作历史。
- “导出收益CSV”：导出总资产快照数据。
- “导出回测CSV”：导出最近一次回测资产曲线和交易点。

### 收益曲线

- 交易后会自动记录一次总资产快照。
- 也可以在“收益曲线”标签页手动点击“记录当前总资产”。

### 首页 / 全球市场看板

- 登录后进入“行情首页”，中间显示大盘/期货K线走势图。
- 支持切换各国/地区指数：上证、深证、恒生、日经、标普、纳指、道指。
- 支持切换期货示例合约：`ES=F`、`NQ=F`、`YM=F`、`GC=F`、`CL=F`。
- K线数据通过 `yfinance` 拉取，支持 `1mo`、`3mo`、`6mo`、`1y`、`2y` 周期。
- 右侧金融资讯栏目会拉取所选市场、美国指数和主要期货相关新闻，双击可打开原文。
- 顶部和侧栏继续显示实时行情价格，随轮询自动刷新。

### 真实交易规则模拟

当前内置的是训练级规则引擎，不替代券商/交易所真实校验：

- A股：买入按 100 股整数倍；禁止裸卖空；模拟 T+1，当日买入不可当日卖出。
- 港股/日股：按 100 股整数倍买入；禁止裸卖空。
- 美股/国际股票：默认 1 股起；禁止裸卖空。
- 单笔交易上限和总风险敞口限制仍然生效。

### 期货模拟

- 支持示例合约：`ES=F`、`NQ=F`、`YM=F`、`GC=F`、`CL=F`。
- 买入表示开多/加多；卖出在无多仓时表示开空，有多仓时优先平多。
- 按合约整数手交易。
- 使用合约乘数和保证金率计算保证金占用。
- 平仓时释放保证金并结算盈亏。

### 回测

- 当前支持基础均线交叉策略：快均线上穿慢均线买入，快均线下穿慢均线卖出。
- 支持周期：`3mo`、`6mo`、`1y`、`2y`、`5y`。
- 回测参数会自动保存到 SQLite，下次登录继续使用。
- 回测结果包含最终资产、策略收益、买入持有收益和最近交易点。
- 可导出回测 CSV，也可导出 HTML 回测报告。

### K线图

- 在“股票搜索 / 自选股”中输入代码后，点击“绘制K线”。
- 当前绘制最近 60 个交易日的日K线，红色表示收盘不低于开盘，绿色表示下跌。

## 9. 本地优化记录

当前本地工作副本已做两轮优化：

- 增强账户安全：密码哈希、注册校验、兼容旧数据迁移。
- 增强数据可靠性：`users.json` 原子写入；损坏 JSON 自动备份。
- 增强交易校验：数量/价格必须为正数，避免负数、NaN 等异常交易。
- 增强行情体验：增加刷新状态、手动刷新按钮、行情失败提示。
- 增强持仓视图：显示现价、市值和浮动盈亏。
- 新增股票搜索、自选股、交易记录导出、收益曲线、基础均线回测。
- 新增首页启动页、SQLite 数据库存储、旧 JSON 自动迁移、策略参数保存。
- 新增 K线图、HTML 回测报告导出、Windows exe 打包。
- 修正数据文件路径：固定写入脚本所在目录，避免从不同工作目录启动时找不到用户数据。
